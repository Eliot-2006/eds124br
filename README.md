# Teaching Programming Portfolio

My teaching programming portfolio for **EDS 124BR: Teaching Computational Thinking for Everyone** at UC San Diego.

The site documents my coursework and learning throughout the quarter, including programming projects, teaching demonstrations, and reflections.

Built with plain HTML and CSS and hosted with GitHub Pages.

## Preview locally

Open `index.html` directly in your browser, or run:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`. Stop the server with Ctrl+C.
